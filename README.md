# 夏天婚纱 · 小红书聚光投放工作台（演示版）

> 这是「1024 超能 Coding 周末 · 办公赛道」的演示作品。
> 所有数据均为**虚构演示数据**：品牌「夏天婚纱摄影」、城市、账号 ID、投放金额、素材标题全部为演示用途生成，不含任何真实业务数据、公司信息与凭据。

---

## 这个工作台是什么

给「夏天婚纱摄影」这个 16 城连锁品牌的市场投放运营搭的 AI 工作台：
每天上班先打开它，重复的活交给它。

**核心链路（一条命令自动完成）**

```
定时触发 → 从聚光开放平台拉取全部投放账户数据 → 数据质量校验 → 生成日报 → 刷新投放看板
```

**每天真在做的 3 件事**

1. **盯投放 KPI**：消耗、点击率、开口率、留资率、客资成本、点击成本（昨日/近3日/近7日/本月/上月/季度/半年/一年随意切）
2. **盯素材获客榜**：每一条素材的封面、归属门店账号、消耗/展现/点击/CTR/私信/留资/留资成本，按城市/投放账户/小红书账号三个维度联动筛选
3. **盯授权与账户**：新门店来了怎么授权、哪些账号 token 快过期、哪个投放户在花预算

**进阶能力（做到了加分）**

- ✅ 接真实数据：聚光开放平台离线报表接口（账户/计划/单元/创意/笔记/关键词 6 个维度）
- ✅ 自己跑起来：WorkBuddy 定时任务每天 10:30 自动触发，到点自动拉数、自动出日报
- ✅ 换人也能用：授权面板在线完成新主体授权，账号命名自动按城市业务线区分（如「青岛·主号」）

## 常见问题

**为什么「授权管理」里有一个待授权账号？**
故意保留了一个演示项：用于展示「新门店来了怎么一键授权、换人也能用」的进阶场景，账号名与门店信息均为虚构。

**为什么点击「刷新」提示授权失败？**
演示版没有真实 token（出于安全全部移除），拉数接口会返回未授权；页面展示的全部数据来自本地演示数据，不影响演示。

**服务会自动拉数吗？**
不会。服务带「演示模式保护」：启动时检测到账号库中全部为 demo 占位授权，即跳过拉数、直接使用本地演示数据，并在日志输出 `演示模式：无有效授权，跳过拉数`。接入真实授权后自动切换为正常拉数。

**比赛交付物在哪？**
见同目录 `比赛交付物.md`（作品一句话介绍、三句话人物卡、3 分钟录屏分镜脚本 + 口播稿、提交文案、关键数字备查）。
