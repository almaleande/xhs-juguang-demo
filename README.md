AI 驱动 · 自动分析与投放决策

> 这是「1024 超能 Coding 周末 · 办公赛道」的演示作品。
> 工作台品牌与凭证已作演示化处理，真实授权入口已关闭。封面和标题使用用户提供的摄影图片及匹配的抓取原始标题，仅作演示，不代表图文与历史投放数据真实对应。现有指标数值保持不变，本轮未核验其生成来源，外发前请确认经营数据和图文使用权限。详见 `脱敏说明.md`。

## 这个工作台是什么

给「示例婚纱摄影」这个 16 城连锁品牌的市场投放运营搭的 AI 工作台：
每天上班先打开它，重复的活交给它。

**核心链路（一条命令自动完成）**

```
读取本地演示缓存 → 本地聚合 → 生成日报／刷新投放看板
```

**每天真在做的 3 件事**

1. **盯投放 KPI**：消耗、点击率、开口率、留资率、客资成本、点击成本（昨日/近3日/近7日/本月/上月/季度/半年/一年随意切）
2. **盯素材获客榜**：每一条素材的封面、归属门店账号、消耗/展现/点击/CTR/私信/留资/留资成本，按城市/投放账户/小红书账号三个维度联动筛选
3. **看账户总览**：展示虚构账号、演示授权状态与投放账户归属，不显示凭证

**进阶能力（做到了加分）**

- ✅ 本地演示：覆盖账户/计划/单元/创意/笔记/关键词等维度，保留生产链路代码供参考，外部 API 请求固定禁用
- ✅ 一键运行：内置缓存，无需真实账号或定时采集
- ✅ 换人也能用：授权面板仅展示账号总览，真实授权与凭证输入已移除

## 看板有什么

| 卡片 | 内容 |
|---|---|
| 总览 | 素材转化漏斗 · 留资成本分布 · 投放账户概览 |
| 素材榜 | 素材获客榜（封面+效果+效率标签）· 城市/账户/账号维度联动 |
| 归属树 | 店铺 → 账号 → 投放户 → 素材 四级折叠树 |
| 预警 | 高耗无转化素材 |
| 投放账户 | 账户明细 |
| 说明 | 数据源与口径 |
| 关键词 | 投放关键词表现 |
| 投放诊断 | 计划/单元级诊断 |

**时间段切换**：昨日 / 今日 / 近 3 日 / 近 7 日 / 本月 / 上月 / 本季度 / 近半年 / 近一年 / 自定义
（短区间走素材级数据，长区间走账户日粒度本地聚合，切换零请求、秒出。）

**口径提示**：KPI 消耗默认创意口径（偏小）；区间视图为账户口径（更接近真实花费），页面副标题有标注。

## 演示数据说明（重要）

- 工作台品牌、账号名已改为示例内容；547 条素材记录使用匹配新封面来源的 21 条抓取原始标题，标题允许重复；不导入账号或来源链接。城市为现实地名，仅作演示标签。金额保持现有数值，本轮未重新合成
- 数据时间范围：2026-07-25 ~ 2026-10-24（92 天账户日数据）；演示“今日”固定为 2026-10-24，三页「昨日」统一为 2026-10-23，关键词日库也覆盖该日，不随系统日期漂移取空。可用 KB_REF_DATE 显式覆盖基准
- token / app_secret：**全部为 demo 占位符**；本版本固定关闭真实授权，不支持填入凭证后自动转生产
- 素材封面图：190 张已全部替换为用户提供的新摄影图片，短边至少 1080 像素，保持原始比例，不依赖外网加载；清除图片文件元数据，保留画面原有标记。含真实人像，不属于完全匿名素材；仅作演示配图，不与历史投放数据建立真实对应关系
- 投放诊断：演示模式会自动生成「计划级」虚构诊断数据（含高耗无转化、出价偏低等规则标签），昨日/近3日/近7日/本月/上月/本季度/近半年/近一年 8 个档位均已备好，切换即开

## 常见问题

**为什么「授权管理」里有一个待授权账号？**
故意保留了一个演示项，用于展示账号状态。不能在本版本完成真实授权。

**刷新会读取真实数据吗？**
不会。「刷新」仅重新载入本地缓存；「刷新余额」已禁用，防止覆盖演示数据。

**服务会自动拉数吗？**
不会。`core/privacy.py` 固定启用演示保护，真实授权、凭证保存和聚光外部请求均被拦截，不会因填入真实授权而自动切换生产。

**比赛交付物在哪？**
见同目录 `比赛交付物.md`（作品一句话介绍、三句话人物卡、3 分钟录屏分镜脚本 + 口播稿、提交文案、关键数字备查）。
